# CyberShield

CyberShield is developed to protect and handle datas in secure ways by avoiding phishing and cyber attacks.

## Installation

Download the Node js latest release to install the Cyber Project (https://nodejs.org/en/download/current)

Get into git folder and in command prompt give

```bash
git install https://github.com/Adithyavarun-creator/cybercode.git
```

You can see two folders frontend and backend
Frontend is devleloped with Reactjs v19 which is stable and Nodejs for backend

For installing on running backend

## Usage

```python
1.cd backend
2.give ==> npm install or npm i
3.then ==> npm start
Your backend runs at local port 5000
```

For installing Frontend

## Usage

```python
1.cd frontend
2.give ==> npm install or npm i
3.then ==> npm run dev
Your frontend runs at local port http://localhost:5173/
```
